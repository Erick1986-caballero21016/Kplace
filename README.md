# KPlace · Mike AI — prueba sin servidor

Subí a la raíz de tu repositorio GitHub Pages: `index.html`, `kplace.html`, `assets/` y `favicon.svg`. `robots.txt` es opcional. No subas una carpeta `server/`: esta versión llama a Gemini directamente desde el navegador.

## Importante

Esta versión es únicamente para pruebas. La clave Gemini está en `index.html` y cualquier persona que abra el sitio puede verla y usarla. Revocá esta clave al terminar la prueba y restringí su uso desde Google AI Studio si está disponible. No uses esta configuración en producción.

La voz Live requiere permiso de micrófono, HTTPS y que el modelo esté habilitado para la clave/cuenta. Se revisó la sintaxis y la estructura localmente, pero no se verificó una sesión real contra Gemini.
